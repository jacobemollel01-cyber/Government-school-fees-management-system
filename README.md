# Government School Fees Management System

A PHP and MySQL web application designed to help schools manage student records, fee payments, sponsorships, contributions, expenses, and financial reports.

## Features

- **Student Management** — Add, edit, view, and manage student records.
- **Fee Payments** — Record and manage school fee payments.
- **Sponsorship Management** — Track sponsors and sponsorship records.
- **Contributions Tracking** — Manage financial contributions.
- **Expense Management** — Record and review school expenses.
- **Financial Reports** — Generate reports for classes, students, and sponsorships.
- **Administration** — Access administrative dashboards and fee thresholds.
- **Authentication** — Login, logout, and password management.

## Technology Stack

- PHP
- MySQL

## Local Installation

1. Install [XAMPP](https://www.apachefriends.org/).
2. Copy the project folder into XAMPP's `htdocs` directory.
3. Start Apache and MySQL.
4. Create a MySQL database named `school_fees`.
5. Import the project's database schema once a schema file is provided.
6. Configure your local database credentials in `config/db.local.php`, using `config/db.local.example.php` as a template.
7. Open `http://localhost/school-fees/` in your browser.

**Note:** The database schema must be supplied separately before a fresh installation can be completed.

## Security

- Never commit local database credentials or private database exports.
- Use sample data for demonstrations.
- Configure strong passwords and appropriate access controls before deployment.
